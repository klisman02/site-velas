# Backend - Velas Artesanais

Pasta reservada para os arquivos de backend da aplicação.

## 📝 Estrutura Recomendada

```
backend/
├── app.py              # (Python) ou server.js (Node.js)
├── requirements.txt    # (Python) ou package.json (Node.js)
├── models/             # Modelos de dados
├── routes/             # Rotas da API
├── controllers/        # Lógica de negócio
├── middleware/         # Middlewares
├── config/             # Configurações
└── .env.example        # Variáveis de ambiente exemplo
```

## 🔧 Tecnologias Sugeridas

### Python
- **Framework**: Flask ou Django
- **Banco de Dados**: SQLite, PostgreSQL
- **ORM**: SQLAlchemy

### Node.js
- **Framework**: Express ou NestJS
- **Banco de Dados**: MongoDB, PostgreSQL
- **ORM**: Sequelize, TypeORM
